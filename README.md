## Overview

Achievement Watcher Next scans local save data and application directories to aggregate and display unlocked achievements from Steam, GOG, Epic Games Store, and a wide range of emulated retro titles — all in a unified interface without requiring any platform login. It operates completely offline, shows achievement artwork, unlock timestamps, and completion percentages per game, and supports importing additional achievement sources via community plugins.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Achievement Watcher Next** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multi-Platform Scanning** | Aggregates Steam, GOG, Epic, and emulated game achievements in one view |
| **Fully Offline** | Reads local save data only — no platform account login required |
| **Achievement Artwork** | Displays achievement icons, unlock descriptions, and timestamps |
| **Completion Stats** | Per-game and global completion percentage with rarity indicators |
